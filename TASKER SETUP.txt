NOVA AUTO XR — QUICK REFERENCE

Install: follow README.md. Import the project only once.

MANUAL ADB ALTERNATIVE (skip if Install XR Helpers was used)
  adb push scripts/nova-xr-ratio.sh /data/local/tmp/
  adb push scripts/nova-xr-wake.sh /data/local/tmp/
  adb shell su -c "chmod 700 /data/local/tmp/nova-xr-ratio.sh /data/local/tmp/nova-xr-wake.sh"

Profiles / tasks:
- HDMI Plugged -> Switch Ratio -> root shell: sh /data/local/tmp/nova-xr-ratio.sh
- HDMI Plugged (inverted) -> wait 2 seconds -> same root helper
- Display On -> XR Wake Reblank -> root shell: sh /data/local/tmp/nova-xr-wake.sh
Run Shell timeout: 0. The helper checks physical DP status before changing size.

BACKGROUND
Android Apps > Tasker > Battery > Unrestricted / exclude battery optimization.
Keep Tasker's foreground monitor enabled. Lock its Recents card, or import
optional/Tasker Hide Recents.prj.xml and grant Usage access.
A manually force-stopped Tasker must be reopened.

CHECK
Connect glasses: 16:9, Nova panel blank, accurate touch markers in glasses.
Sleep/wake: panel reblanks after about 1-2 seconds.
Unplug: native 4:3 and markers off after about 1-2 seconds.

If nothing runs, open Tasker and confirm its profiles and root access.
Check the scripts exist. Don't add an unconditional reset on HDMI disconnect.
Logs: /data/local/tmp/nova-xr-ratio.log and nova-xr-wake.log.

EXPORT / IMPORT
Long-press a bottom project tab > Export > XML to Storage.
On the receiving device: long-press a project tab > Import Project.
Run Install XR Helpers once after import; it carries both helpers inside the project.

REMOVE
Disable the three profiles; unplug glasses and wait at least 3 seconds.
If needed, run:
  adb shell su -c "wm size reset"
  adb shell su -c "settings put system show_touches 0"
Delete the project and its two helpers if wanted. Retroid's screen-off option
can be turned off in Retroid settings. DroidDeck is not modified.
